# -geometry-dash-pygame# Geometry Dash Mini (Pygame)

A simple, fast-paced 2D arcade game inspired by Geometry Dash, built entirely in Python using the `pygame-ce` library. Control a neon cube, dodge obstacles, and survive as long as possible while the game speeds up!

## Features
- **Smooth Physics:** Accurately calculated gravity and jumping mechanics.
- **Dynamic Cube Rotation:** The cube rotates while in the air and automatically snaps perfectly back to flat when landing.
- **Increasing Difficulty:** Obstacles speed up dynamically for every 5 points you score.
- **High Score Tracking:** Keeps track of your best run during the session.

## Controls
- **Spacebar / Up Arrow Key:** Jump over the obstacles.
- **R Key:** Reset and play again instantly after a game over.

## Requirements
To run this game locally, you need Python 3.10+ installed on your computer along with the `pygame-ce` library.

## How to Play
1. Clone or download this repository.
2. Open your terminal or command prompt and install the required library:
   ```bash
   pip install pygame-ce
   ```
3. Run the game using python:
   ```bash
   python main.py
   ```
